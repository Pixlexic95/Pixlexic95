# ✨ Hi, I'm Zoe ✨
A Computer Scientist with a PhD specialising in ethical and trustworthy, underwater marine debris and anthropogenic waste detection.💫

Although this is a portfolio of work and projects I have completed, I have tried my best to provide as much information around each subject as I can and kept it in an accessible, tutorial style so that it can be reproduced. I believe in keeping science ethical and open, so once my research is published, I'll be adding in more information, projects, scripts and the 'science-y' side of my work too.

This project was a part of my PhD Research (*Blender_Renders* in *PhD-Thesis*) and will be continuously updated and improved as papers get published.
